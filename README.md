## 🔑 Core Features Explained (No Technical Knowledge Needed)

### Conversation Memory: Jev-Powered

Cheshi uses something called "Jev" — think of it as an ultra-smart filing system. When you have a conversation with Codex, Cheshi:

- Saves every exchange automatically
- Tags it with context (which project, which file)
- Creates a searchable index of everything discussed

**To find an old conversation:** Simply type what you remember in the search bar — like "deploy script fix" or "database migration" — and Cheshi shows you all relevant sessions.

### Revisiting Decisions with Original Sources

This is Cheshi's superpower. When you scroll back to an old decision, every point is linked to its actual source:

- **Code decisions** → Shows the exact line of code
- **Design choices** → Names the file and folder
- **Configuration changes** → Displays the settings file

Just click any highlighted text to jump straight to the original source file. No more guessing what you meant last week.

### Agent Management

You can have multiple AI agents working on different tasks. Cheshi lets you:

- 🎭 Name each agent (e.g., "Frontend Helper," "Bug Hunter")
- 📋 Assign different projects to different agents
- 🔄 Switch between agents with one click
- 📊 See each agent's history separately

### CodeGraph: Your Code's Map

Imagine your entire codebase as a subway map. CodeGraph shows you:

- 🚉 Every file as a station
- 🛤️ Connections showing which files depend on others
- 🎯 Click any station to open that file immediately

When you're looking at an old conversation about "fixing the login system," CodeGraph highlights all the files related to login in your codebase.

### Built-In Git Worktrees

Git can be intimidating, but Cheshi simplifies it. Every time you start working on a new feature, Cheshi:

1. Creates a separate worktree (like a sandbox) automatically
2. Keeps your main project safe and untouched
3. Tracks all changes in the worktree
4. Merges everything back when you're done

You never need to remember Git commands — Cheshi handles it all in the background.

### Ghostty Terminals Inside Cheshi

Don't jump between apps. Cheshi includes Ghostty terminals right in the interface:

- 🖥️ Open a terminal next to your conversation
- 💬 Ask Codex for a command, then run it instantly
- 📋 Copy/paste between conversation and terminal with ease

### Apple Notes Integration

Have ideas in Apple Notes? Cheshi connects directly:

- 📝 Pin a conversation to a note
- 🔗 Link a note from within a chat
- 🗂️ Organize project thoughts alongside AI conversations

## 🛠️ Troubleshooting Common Issues

### "Cheshi won't open"

This usually happens because macOS blocks apps from unverified developers.

**Fix:**
1. Right-click (or Control-click) the Cheshi icon in Applications
2. Select "Open" from the menu
3. Click "Open" again in the popup window

### "I can't find my old conversations"

Make sure you're using the search bar at the top of the left sidebar, not the regular search on your Mac. Cheshi has its own search index for AI sessions.

### "The app is slow with large projects"

Cheshi is designed to handle big codebases, but here are quick tips:

- Close unused agents (they use resources)
- Use the search bar instead of scrolling
- Quit and reopen Cheshi if it's been running for days
